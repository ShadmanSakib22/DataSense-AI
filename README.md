# DataSense AI

> Ask your data a question. Get an answer.

DataSense is a privacy-first, browser-based data analysis tool. Upload a CSV, Excel file, or SQLite database — ask questions in plain English — get interactive charts and tables instantly.

**Everything runs in your browser.** Your files never leave your device. Your API key is never sent to a server.

---

## Features

- **Natural language to SQL** — Ask questions in plain English, get accurate SQL queries generated by LLMs (Gemini, Groq)
- **AST-based SQL guardrails** — Every generated query is validated through real AST parsing, not regex. Blocks writes, DDL, multi-statement injection, and enforces schema allowlists
- **Multiple file formats** — CSV, Excel (.xlsx/.xls), SQLite databases (.db/.sqlite), and SQL dumps
- **Interactive visualization** — Bar, line, area, pie, and radar charts with tooltips and legends
- **Schema explorer** — Browse table structures and column types
- **Query history** — All queries are saved locally for quick re-execution
- **BYOK (Bring Your Own Key)** — Use your own Gemini or Groq API key. No account required, no data sent to third parties
- **Fully client-side** — SQLite runs in a Web Worker via WebAssembly. No server-side processing

## How It Works

```
┌─────────────────────────────────────────────────────────────┐
│                    Your Browser                              │
│                                                              │
│  1. Upload file ──→ Parse (CSV/Excel) or load (SQLite)      │
│  2. Store in ─────→ In-memory SQLite (sql.js + Web Worker)  │
│  3. Ask question ──→ LLM generates SQL (direct API call)    │
│  4. Validate ─────→ AST guardrail engine checks safety      │
│  5. Execute ──────→ Run SQL against in-browser SQLite        │
│  6. Display ──────→ Interactive charts + tables              │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

1. **Upload** — Select a CSV, Excel, SQLite, or SQL file
2. **Parse** — Files are parsed entirely in the browser (PapaParse for CSV, SheetJS for Excel, sql.js for SQLite)
3. **Store** — Data is loaded into an in-browser SQLite database running in a Web Worker
4. **Ask** — Type a natural language question (e.g., "What are my top 10 albums by streams?")
5. **Generate** — Your LLM provider generates a SQL query from the schema
6. **Validate** — The AST guardrail engine checks the query for safety (no writes, no DDL, valid tables/columns)
7. **Execute** — The validated query runs against your in-browser SQLite database
8. **Visualize** — Results display as interactive charts and tables

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 (App Router), TypeScript |
| UI | Tailwind CSS, shadcn/ui |
| Charts | Recharts (via shadcn charts) |
| SQL Engine | sql.js (SQLite compiled to WebAssembly) |
| File Parsing | PapaParse (CSV), SheetJS (Excel) |
| SQL Validation | node-sql-parser (SQLite dialect) |
| Storage | IndexedDB (via `idb` wrapper) |
| Testing | Vitest |

## Getting Started

### Live Demo

Try DataSense directly in your browser — no installation required:

**[datasense-ai-ss22.vercel.app](https://datasense-ai-ss22.vercel.app)**

### Deploy on Your Own System

#### Prerequisites

- Node.js 18+
- pnpm (recommended) or npm

#### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/DataSense-AI.git
cd DataSense-AI/data-sense-ai

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Using Your Own API Key

1. Click the brain icon in the top right
2. Select a provider (Gemini or Groq)
3. Paste your API key
4. Start asking questions

**Gemini**: Get a free API key at [Google AI Studio](https://aistudio.google.com/apikey)
**Groq**: Get a free API key at [console.groq.com](https://console.groq.com)

## Supported File Types

| Format | Extension | How It Works |
|--------|-----------|--------------|
| CSV | `.csv` | Parsed with PapaParse, loaded into SQLite table |
| Excel | `.xlsx`, `.xls` | Parsed with SheetJS, each sheet becomes a table |
| SQLite | `.db`, `.sqlite` | Loaded directly into sql.js |
| SQL Dump | `.sql` | Executed to rebuild database |

---

## Security

- **No server uploads** — Files are parsed and stored entirely in your browser
- **No tracking** — No analytics, no cookies, no telemetry
- **API keys stay local** — Keys are stored in localStorage, never sent to our servers
- **AST validation** — Real SQL parsing, not regex pattern matching
- **Sandboxed execution** — SQLite runs in WebAssembly, isolated from your system
